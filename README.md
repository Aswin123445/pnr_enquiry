# RailConnect 🚆

RailConnect is a mini project built using the Django framework that allows users to fetch and check railway PNR status easily.  
The project demonstrates Django backend development, API integration, and template rendering.

---

## 📌 Features

- Fetch real-time PNR status
- Simple and clean UI
- Django-based backend
- API integration
- Lightweight and beginner-friendly project

---

## 🛠️ Tech Stack

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite3
